# Restaurant Website Starter

Open `index.html` to preview the website.

Included:
- Two-section interactive food orbit
- Large center meal card with actual ZMW price
- Categories
- Specials
- Cart with quantities and totals
- Delivery/pickup checkout
- Payment-method selection placeholder
- Order tracking interface
- Mobile responsive design
- About/contact placeholders
- User-provided food image used as visual inspiration

## Adding real payments
The checkout is ready for a payment-provider integration, but real payment processing requires a merchant account and provider API credentials. Keep secret credentials on a backend/server, not in `script.js`.

## Add your contacts later
Replace the placeholders in the Contact section in `index.html`.

## Admin dashboard
Open `admin.html` for the demo restaurant admin dashboard. It includes order management, menu management, sales summary and settings. For production, replace browser localStorage with a secure backend/database and authenticate the admin area.
